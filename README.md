# Проект

## 1. Запуск проекта

1. Запускаем `DownloadSputnicImages.py`, чтобы скачать спутниковые снимки.
2. Запускаем `DoTiffFiles`, чтобы получить из скачанных тайлов цельное изображение.
3. Запускаем `MergeBlock.py` и `MergePixels.py`, чтобы получить итоговый результат.
4. Запускаем `ViewFiles.py`, чтобы визуально сравнить результаты разных методов склейки.

---

## 2. Задачи

1. Создать markdown-файлы, в которых будет храниться информация о проекте, о предстоящих задачах, а также изучить различные методы склейки _(21.10.2026)_.
2. Внедрить изученные методы склейки в проект, чтобы на выходе получать уже презентабельный результат _(26.10.2026–02.11.2026)_.
3. После внедрения изученных методов склейки протестировать алгоритмы и выявить лучший.
4. Начать обучать модель на полученных данных, разбиваем наши результаты на разные датасеты, training и testing.
